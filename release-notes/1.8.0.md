## What's changed in 1.8.0: security update

A full security audit of Postarr, testing it against cross-site scripting, request forgery, token theft, session
forgery, path traversal, server-side request forgery, open redirects, malicious uploads and password guessing. Every
problem found is fixed in this release. **Updating is recommended.**

**After updating you'll be asked to sign in once more**, because sessions are now signed with a new key.

### Fixed

- **Secrets in the log:** saving settings wrote the request (including any API key, token or new password you'd just
  typed) to Postarr's console log, which Docker keeps (`docker logs`). It's no longer logged.
- **Cross-site scripting:** titles and names from TMDB, Plex and others containing a `"` could add their own code to
  the page. All text shown on the page is now fully escaped.
- **Token theft through "Test" and "Save":** with a session (or code running in the page), Postarr could be pointed at
  another server address and would send it your saved Plex token or Jellyfin/Emby key. A saved token is now only ever
  sent to the address it was entered for. Change the address, and you type the token again.
- **Request forgery:** a page on another site, or another port or subdomain of the same host, could make your signed-in
  browser change things in Postarr. Changes are now accepted only from Postarr's own pages.
- **Session forgery from a database copy:** sessions were signed using the password hash, so anyone with a copy of the
  database (such as a downloaded backup) could make a login cookie. They're now signed with a random key kept in its
  own file.
- **Sign out** now really ends the session, even if the cookie was copied.
- **Password changes need the current password**, and so do changing the username and turning login off.
- **Lockout behind a proxy:** behind Cloudflare or a reverse proxy, one person's wrong passwords locked everyone out.
  The lockout now applies to the real client address.
- **Clickjacking:** Postarr can no longer be shown inside another site's frame. Browsers are also told not to guess
  file types, and not to pass Postarr's address to other sites.
- **Uploads** are checked and re-saved as JPEG: no SVG or HTML disguised as an image, and no oversized "decompression
  bomb" images that could exhaust memory. Downloaded artwork is checked the same way.
- **Image proxy** only passes real images, and a redirect trick using a tab character is closed.
