## What's changed in 1.7.7

**New: automatic database backups, with one-click restore.**

Postarr's own database holds every poster and background you've chosen, your settings and your collections. Postarr
now looks after it:

- **Every day:** a copy is taken while Postarr runs (SQLite's online backup, so it's always consistent). The newest
  14 are kept; change the number, or turn daily backups off, in **Settings → Backup**.
- **Before every update:** the first time a new version starts, the database is backed up before it's upgraded.
  This release does it too, so installing 1.7.7 leaves you a backup straight away.
- **Back up now:** a button in Settings → Backup.
- **Download:** save any backup somewhere else, such as another drive, a NAS or cloud storage.
- **Restore:** pick a backup and confirm. Postarr first saves your current database as a "before restore" backup, so
  a restore can always be undone. It then restarts on the chosen backup (the Windows service and Docker restart it
  automatically).

Backups are stored in `Backups\Database` inside Postarr's data folder (`C:\ProgramData\Postarr` on Windows,
`/config` in Docker). The newest pre-update and pre-restore copies are always kept, however many backups you choose
to keep.
