## What's changed in 1.7.8

**Fix: scans stopped on their own with "Scan cancelled by user".**

When your media server was slow to answer a single request, for example a poster upload while Plex is busy
(scanning, or just after its database was restored), the request timed out. Postarr mistook the timeout for you
pressing Cancel and stopped the whole scan. The next scan then stopped at the next slow reply.

- **A timeout is now an error for that one title, and the scan carries on.** The Activity log says e.g. *"Couldn't
  push the poster for 'Antz' to Plex: it didn't respond in time - Apply All will push it."* The artwork stays chosen
  and marked "not applied", so **Apply All** (or Health → *Not applied*) pushes it once the server has caught up.
- **Postarr waits longer for Plex:** 60 seconds instead of 30, so a busy server gets more time before a request counts
  as failed.
- Only pressing Cancel now shows **"Scan cancelled."**
