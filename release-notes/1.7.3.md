## What's changed in 1.7.3

**New: your artwork choices survive when your media server re-adds a title.**

Plex (and Jellyfin / Emby) give a title a brand-new ID when it's re-added: a library deleted and re-created,
files moved to another folder or drive, or a file replaced with a new download. Until now Postarr saw a brand-new
title. It picked a fresh poster, lit up the NEW badge, and the next scan removed the old record together with
your chosen poster and the backup of the original artwork.

Postarr now recognises the same title (same TMDB / TVDB / IMDb id) whose old ID the server no longer has, and
carries everything over to the new ID:

- your chosen poster, background and season posters, which are pushed to the server again (straight away
  with *Auto-apply on scan*, otherwise via **Apply All**)
- the stored backups of your original artwork
- the original added date, so re-added titles don't get a NEW or NEW SEASON badge

The Activity log lists each title it carried over. Artwork you'd picked from the server's own images, or
uploaded yourself, lived on the old server item and can't come across. Those titles get a fresh automatic pick.

It only happens when it's unambiguous. If the old ID still exists on the server (for example the same film in a
4K and an HD library), nothing is merged.
